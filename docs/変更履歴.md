# 変更履歴

## 1.0.6

### 改善
- 対象のファイルが見つからない・読み取れない場合に、専用のエラー（E210）で知らせるようにした。従来は「SEARCH部が見つからない」と表示され、原因が分かりにくかった。メッセージには Graft が実際に確認した絶対パスを添える
- 解析（ドライラン）のときに、対象ファイルごとの「絶対パス・存在の有無・行数」をログへ記録するようにした。うまく取り込めないときの原因調査に使える
- 長いパス用の内部処理を見直し、必要な長さのときだけ特殊な形式のパスを使うようにした（ネットワークドライブ上での不確実性に対する予防）

## 1.0.5

### 改善
- 取り込みに失敗したとき、ブロックが閉じられていない箇所を具体的に案内するようにした。「1行目のブロックが閉じられていないまま、5行目で次のブロックが始まっています」のように、開始行と衝突した行の両方を示す
- AIへの指示文を改善した。ブロックの閉じ忘れが起きにくいよう注意点を加え、コードブロックの書き方（1行目・最終行に何を書くか、本文に ``` を含む場合の書き方）を具体的に示すようにした

## 1.0.4

### 改善
- コードエディタのスクロールバーを1.5倍の太さにして掴みやすくした
- スクロールバーのつまみに下限を設け、行数の多いファイルでも極端に短くならないようにした
- AIへの指示文（プロンプト）に「パッチ全体をコードブロックで囲んで出力する」旨を追加した。AIの回答をコピーボタンでまとめてコピーできるようになる
- コードブロックで丸ごと囲まれたパッチも、クリップボード監視で自動検知できるようにした
- 「初回用（完全版）」の指示文に、記号のエスケープ規則の説明を追加した

### 修正
- コードエディタで、本文の右端と最終行がスクロールバーに隠れることがある不具合を修正した
- AIへの指示文をコピーしただけで、パッチとして誤検知されることがある不具合を修正した

## 1.0.3

### 追加
- テーマを9種類から選べるようにした（ライト／ダークに加え、セピア・GitHub・Solarized Light／Dark・Nord・Dracula・ナイト）
- 本文と等幅の書体を、それぞれ設定から選べるようにした
- インデントガイド（字下げの位置を示す縦線）を追加した。「表示しない」「折りたたみできる範囲のみ」「すべての字下げ」から選べる
- 折りたたみを拡張した。マーカーにマウスを乗せると対応する範囲が強調され、「すべて折りたたむ」「すべて展開する」「コメントをまとめて折りたたむ」をコマンドパレットから実行できる
- コードの中の色（`#RRGGBB`・`rgb()`・`hsl()`）の手前に色見本を表示し、クリックすると色を選び直せるようにした。書き換えても元の書き方（大文字小文字・桁数・区切り方）はそのまま保たれる
- Markdownの編集を補助するようにした。リストや引用はEnterで続きが作られ、空のままEnterを押すと抜けられる。表の中ではTabとShift+Tabでセルを移動でき、最後のセルでEnterを押すと行が増える
- ツールチップの詳しさを4段階（詳しい／ふつう／最低限／表示しない）から選べるようにした

### 改善
- 折りたたみマーカーから伸びていた縦線と横線（L字の線）を表示しないようにした
- 折りたたみマーカーの左右の余白を広げ、左右対称にした
- 行番号や折りたたみの帯の上では、マウスカーソルが矢印になるようにした（従来は文字入力用の形のままだった）

### 修正
- Markdownプレビューで、コードブロックや表に横スクロールバーが出たとき、最後の行に重なって読めなくなる不具合を修正した
- 折りたたみマーカーにマウスを乗せたとき、縦線の強調がちらつく不具合を修正した。あわせて、カーソルを動かすたびに画面全体のレイアウトを計算し直していた無駄も解消した
- ファイルの削除を続けて行ったとき、ごく稀にアプリが停止することがある不具合を修正した（削除の取り消し用の記録が、複数の処理から同時に書き換えられていた）

## 1.0.2
