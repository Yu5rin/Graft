# Graft {VERSION}

Graftは、**AI（ChatGPT・Claudeなど）が提案したコードの変更を、手元のプロジェクトへ安全に取り込むためのデスクトップアプリ**です。

AIにコードの修正を頼むと「このファイルのこの部分をこう直してください」という形で回答が返ってきます。それを手作業で写すのは、範囲が広くなるほど手間がかかり、写し間違いも起きます。Graftは、AIに決まった書式で回答してもらい、その回答を読み取って実際のファイルへ機械的に適用します。

書き込む直前には必ずバックアップを取るので、結果が気に入らなければいつでも元に戻せます。

これが最初の公開版です。

---

## 動かすには

- **Windows 10 / 11（64bit）**
- .NET のインストールは不要です（同梱しています）
- インストーラはありません。ZIPを展開して `Graft.exe` を実行してください

## 導入手順

1. 下の `Graft-{VERSION}-win-x64.zip` をダウンロードする
2. 好きな場所に展開する（例: `C:\Tools\Graft`）
3. `Graft.exe` を実行する

初回起動時に「Graftへようこそ」という案内が開きます。3画面進むだけでひととおりの流れを体験できます。自分のプロジェクトを使わずに試したい場合は、案内の2画面目にある **「サンプルで試す」** を押してください。一時フォルダに練習用のファイルが作られ、あなたのフォルダには一切触れずに、解析から適用までを実際に体験できます。

> Windows の SmartScreen が「WindowsによってPCが保護されました」と表示することがあります。コード署名証明書を付けていないためです。内容を確認のうえ「詳細情報」→「実行」で起動できます。

## 何ができるか

### 基本の流れ

1. Graftから「この形式で答えてください」という指示文をコピーし、AIとの会話の最初に貼り付ける
2. AIに直してほしい内容を伝え、回答をコピーする
3. Graftへ貼り付けて解析する（Ctrl+Shift+V）
4. どう変わるかを差分で確認し、要らない変更はチェックを外す
5. 適用する（Ctrl+Enter）

### 主な機能

| | |
|---|---|
| **クリップボード監視** | AIの回答らしき内容がコピーされたことを自動で検知します。検知時の挙動（自動解析・前面に表示・通知のみ）は選べます |
| **履歴と復元** | 適用するたびに記録され、1件だけ取り消す／ある時点までまとめて戻す、が選べます。ファイル単位での絞り込みもできます |
| **コンテキスト収集** | AIに渡すコード一式を組み立ててコピーします。「ツリーのみ」「選択ファイルの中身も」「前回からの差分のみ」を選べ、推定トークン数も表示します |
| **コードエディタ** | シンタックスハイライト、折りたたみ、横断検索、クイックオープン（Ctrl+P）、コマンドパレット（Ctrl+Shift+P） |
| **Markdownプレビュー** | `.md` ファイルを装飾表示します。チェックリストはその場で操作でき、Ctrl+Zで戻せます |
| **Git連携** | 行番号の脇に追加・変更・削除を色で表示します。適用後の自動コミットも設定できます（既定オフ） |
| **適用後フック** | 適用が成功したらフォーマッタやテストを自動実行できます |

### 安全機構

- 適用のたびに自動バックアップ（保持数は設定可能）
- 適用前のプレビュー（設定でオン／オフ）
- 対象パスがプロジェクトの外を指していないかの検査
- 適用済みパッチの再投入を検知
- 起動時にバックアップと履歴の整合性を検証

取扱説明書は **F1** でいつでも開けます（ZIPにも `取扱説明書.md` として同梱しています）。

## データの保存場所

既定では **`Graft.exe` と同じフォルダ**（ポータブル）に、設定・プロジェクト一覧・履歴・バックアップを保存します。フォルダごとコピーすれば、別のPCへそのまま持ち運べます。

`Program Files` など書き込めない場所に置いた場合は、設定→一般の「ユーザーフォルダへ移動」で `%APPDATA%\Graft` へ移せます。

> **更新するときの注意**: ユーザーフォルダへ移した場合、保存先を指す `datapath.txt` が `Graft.exe` と同じフォルダに置かれます。新しい版へ差し替える際にこのファイルごと消してしまっても、Graftが起動時に「以前ユーザーフォルダに保存したデータが見つかりました」と尋ねるので、そこから復帰できます。

## 既知の制限

- **Windows のみ動作確認済み**です。Linux 版もビルドできますが、実際のデスクトップ環境での検証は行っていません
- コード署名証明書を付けていないため、SmartScreen の警告が出ます
- インストーラはありません（ZIP展開のみ）
- 単一ファイル発行のため、初回起動時にファイルの展開が入り、2回目以降より少し時間がかかります

## 不具合の報告

うまく動かないときは Issue でお知らせください。次の情報があると調べやすくなります。

- Windows のバージョン
- 何をしたときに、何が起きたか
- `logs\<日付>.log` の該当時刻あたり（設定→バージョン情報→「ログフォルダを開く」から辿れます）

エラー画面には「詳細をコピー」ボタンがあります。押すと原因の特定に必要な情報がまとめてコピーされます。
