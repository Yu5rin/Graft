## 導入

お使いのOS向けの書庫を、展開したフォルダごと専用の場所（他のアプリと混ざらない
場所）へ置いてください。フォルダの中には実行ファイル（Windowsは `Graft.exe`、
Linuxは `Graft`）とネイティブライブラリ（Windowsは3つ、Linuxは2つ）が入っています。
実行ファイルだけを取り出さず、フォルダごと扱ってください（同梱のライブラリが
ないと起動できません）。実行ファイルと同じ階層に `settings.json` /
`projects.json` / `back/` / `logs/` を作ります。

Windowsでは、実行ファイルのショートカットをデスクトップやスタートメニューへ
作っておくと起動が楽になります。

Linux では実行権限の付与が必要な場合があります。

```
chmod +x Graft
```

.NET ランタイムの導入は要りません（自己完結型）。

## 動作環境

- Linux（x64、X11）
